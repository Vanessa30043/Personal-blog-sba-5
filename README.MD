🗂️ Interactive Personal Blog

A simple client-side personal blog platform that allows users to create, edit, and delete posts. All posts are displayed dynamically on the page, and data persists in the browser using Local Storage so posts remain even after refreshing the page.

📘 Description

This Interactive Personal Blog was created as part of a front-end JavaScript learning project. It demonstrates how to use HTML, CSS, and JavaScript together to build a functional and dynamic web application. Users can:

Create new blog posts with a title and content.

Edit existing posts and save changes.

Delete posts from the page.

Persist posts in the browser using Local Storage, so all entries remain after page reloads.

The project emphasizes beginner-friendly coding concepts taught in the Per-Scholas curriculum (Lessons 1–5), such as:

DOM element selection

Event listeners

Form validation

Array manipulation

Local Storage

🚀 Getting Started ✅ Dependencies

Any modern web browser (Chrome, Firefox, Edge, Safari)

Basic operating systems: macOS, Windows, Linux

Internet connection only for initial setup or viewing tutorials

💾 Installing

Clone or download the repository:

git clone https://github.com/Vanessa30043/interactive-personal-blog.git


Open the project folder in VS Code or your preferred code editor.



▶️ Executing Program

Open index.html in your web browser, or use Live Server in VS Code.

Use the input form to:

Enter a post title

Enter post content

Click Add Post to add it to your list.

Posts will appear  below the form.

Use Edit or Delete buttons to manage posts.

All posts are automatically saved in Local Storage.



🛠️ Help

If posts are not saving after refresh:

Check if your browser has Local Storage enabled.

Try clearing Local Storage and reloading:

localStorage.clear()
